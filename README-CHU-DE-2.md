# Bổ sung Chủ đề 2 cho RenToan v1.1

Gói này chỉ chứa các file mới hoặc file cần ghi đè.

## Cách cài

1. Giải nén file ZIP.
2. Sao chép toàn bộ các thư mục `lop-8` và `assets` vào thư mục gốc repository RenToan.
3. Chọn ghi đè khi GitHub hỏi xác nhận.
4. Cấp quyền chủ đề cho học sinh trong Firestore bằng một trong hai cách:
   - thêm `lop8-chude2` vào `allowedTopics`;
   - hoặc giữ quyền theo toàn bộ lớp 8 nếu hồ sơ đang dùng `allowedGrades: [8]`.

- `lop-8/chu-de-2/index.html`
